# 研究成果与实验报告

最后更新：2026-10-12

成果可以是带源码证据的讨论分析、可运行的复现、对照实验，或有数据支持的优化。使用[报告模板](../templates/report.md)，保存至 `reports/<experiment>/<run-id>/README.md`。纯阅读分析可使用 `reports/<topic>/README.md`，明确标记尚未实测。

## 公开验证标准

1. 问题和原始来源清楚，区分原作者主张、推断和实测。
2. 主仓库与 submodule 提交可获取，源码永久链接可定位。
3. 硬件、依赖、驱动、构建方式、实际加载的代码版本完整。
4. 模型与输入版本、完整命令、变量控制和统计口径明确。
5. 保留输出正确性或质量检查；性能结论同时说明资源与质量代价。
6. 小型原始数据、失败记录和生成图表的方法齐全；大产物提供可访问位置与校验值。
7. 结论有适用范围，说明未测试条件、反例和其他解释。

“未观察到提升”或“无法在当前环境复现”也可以成为成果；记录实际做过的检查与限制。使用他人数据要注明“公开数据重分析”，不要写成自己的硬件实测。

Git 不保存模型权重、下载缓存和大体积 trace。发布前检查报告引用、原始数据、产物访问方式，以及日志中是否包含私人数据或凭据。
